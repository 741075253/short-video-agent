# 采用 Kling 图生视频 + 两段式 Pipeline

原视频生成是 FFmpeg `-loop 1` 循环静态图+字幕的幻灯片模式，缺乏真实人物动作表现力。决定引入 AI 图生视频模型 Kling（可灵）将静态关键帧转为 5 秒真实视频片段，采用两段式 Pipeline（文→图→图生视频→FFmpeg 拼接），不改变上游分镜/剧本逻辑。

## 备选方案

- **Wan 2.1 视频版**：同为 DashScope 生态，API 更统一，但图生视频动作质量弱于 Kling，作为后续备选 Provider
- **Kling 文生视频直通式**：跳过生图步骤，但多镜头角色一致性控制远弱于图生视频，不适用
- **本地模型（CogVideoX 等）**：零 API 成本但需要 GPU，动作质量和角色一致性不如 Kling，留作后续扩展
